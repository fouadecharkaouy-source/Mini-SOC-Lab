## 📌 Présentation du projet

Ce projet consiste à mettre en place un Mini Security Operations Center (Mini-SOC) basé sur Wazuh.

L'objectif est de découvrir et de pratiquer les principales activités d'un analyste SOC Junior : collecte des journaux, surveillance des systèmes, détection des événements suspects et enquête des incidents de sécurité.

## 🎯 Objectifs

* Déployer et configurer le serveur Wazuh.
* Connecter l'agent Windows 11 (DESKTOP-DEU5BDJ).
* Collecter et centraliser les journaux système.
* Détecter les activités suspectes.
* Analyser les alertes de sécurité.
* Documenter les enquêtes et les résultats.

## 🛠️ Environnement technique
